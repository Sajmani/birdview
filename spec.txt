# BirdView & BirdView-Ingest: Architecture & System Specification

---

## 1. System Overview & Module Layout

The project lives in a single Go module (`birdview`) with two primary executables:

1. `cmd/birdview-ingest`: Ingestion CLI tool that reads `AVONET Supplementary dataset 1.xlsx` (specifically sheet `AVONET2_eBird`), applies morphometric expansion equations (Option B) to derive macroscopic Total Length ($L$) and Wingspan ($W$), segments the anatomical spine into non-overlapping coordinate partitions, and outputs `web/data/species.json`.
2. `cmd/birdview`: Embeds the static web assets and compiled dataset (`embed.FS`), serves them over HTTP on `localhost:8080`, and provides clean routing and API fallback endpoints.

## 2. Ingestion Pipeline: `cmd/birdview-ingest`

### 2.1 Input Data Source

* **File:** `AVONET Supplementary dataset 1.xlsx`
* **Target Worksheet:** `AVONET2_eBird`
* **Taxonomic Mapping:** Aligned with Clements / eBird taxonomy (`Species2`, `Family2`, `Order2`).
* **Attributes Ingested:**
* `Species2`: Scientific binomial name.
* `Family2`: Avian family name.
* `Order2`: Avian order name.
* `Beak.Length_Culmen`: Exposed culmen length in mm.
* `Beak.Depth`: Bill depth at anterior nares in mm.
* `Beak.Width`: Bill width at anterior nares in mm.
* `Tail.Length`: Central rectrix feather length in mm.
* `Wing.Length`: Unflattened wing chord in mm.
* `Secondary1`: Length of first secondary feather in mm.
* `Hand-Wing.Index`: Aerodynamic aspect ratio index.
* `Mass`: Specimen body mass in grams.

### 2.2 Mathematical Engine: Option B Morphometric Expansion

Because museum skins do not preserve macroscopic lengths, `birdview-ingest` uses aerodynamic and morphometric allometric models to derive macroscopic dimensions ($L$, $W$) from AVONET's specimen-level traits.

#### 1. Wingspan Allometric Expansion ($W$)

Wing chord ($C = \text{Wing.Length}$) measures the folded primary flight feathers from the carpal flexure to the tip of the longest primary. Full wingspan incorporates:

* Two outer wing spans ($2 \times C$).
* Forewing/secondary wing chord expansion factoring secondary feather length ($S = \text{Secondary1}$).
* Thoracic pectoral girdle / trunk breadth ($B_{\text{chest}}$), scaled allometrically by body mass ($M$).

$$B_{\text{chest}} = 10.5 \times M^{0.33} \quad (\text{in mm})$$

$$\text{Wingspan (mm)} = 2.0 \times C \times \left(1.0 + 0.12 \times \frac{S}{C}\right) \times \gamma_{\text{family}} + B_{\text{chest}}$$

where $\gamma_{\text{family}}$ is the family-specific aerodynamic wing camber / aspect multiplier:

* $\gamma_{\text{family}} = 1.15$: Long-winged soaring pelagics, terns, and high-aspect shorebirds (`Diomedeidae`, `Procellariidae`, `Laridae`, `Scolopacidae`, `Falconidae`).
* $\gamma_{\text{family}} = 1.08$: Broad-winged soaring raptors and owls (`Accipitridae`, `Strigidae`, `Cathartidae`).
* $\gamma_{\text{family}} = 1.00$: Balanced passerines, woodpeckers, and doves (`Passerellidae`, `Turdidae`, `Picidae`, `Columbidae`).
* $\gamma_{\text{family}} = 0.92$: Short-winged gallinaceous gamebirds (`Phasianidae`, `Odontophoridae`).

#### 2. Cranial Vault Diameter ($H$)

The cranial vault diameter is derived from the dorso-ventral bill depth at the nares:


$$H = \max(12.0\text{ mm},\ \text{Beak.Depth} \times 1.65)$$

#### 3. Torso Trunk Core ($B_{\text{torso}}$)

The rigid thoracic/pelvic core length is modeled using avian allometric body-mass scaling ($M$ in grams):


$$B_{\text{torso}} = 18.0 \times M^{0.31} \quad (\text{in mm})$$

#### 4. Neck Extension Budget ($N$)

Exposed neck extension varies systematically across functional feeding guilds:


$$N = \eta_{\text{family}} \times B_{\text{torso}}$$

where $\eta_{\text{family}}$ is the neck ratio:

* $\eta_{\text{family}} = 0.85$: Long-necked wading birds (`Ardeidae`, `Anatidae`, `Threskiornithidae`).
* $\eta_{\text{family}} = 0.35$: Shorebirds, gulls, and rails (`Scolopacidae`, `Charadriidae`, `Laridae`, `Rallidae`).
* $\eta_{\text{family}} = 0.18$: Passerines, raptors, woodpeckers, and kingfishers (`Turdidae`, `Parulidae`, `Accipitridae`, `Picidae`, `Alcedinidae`).
* $\eta_{\text{family}} = 0.08$: Compact owls (`Strigidae`, `Tytonidae`).

#### 5. Total Length ($L$) Closed Axial Budget

Total Length ($L$) is defined strictly as the sum of its non-overlapping segments:


$$L = \text{Culmen} + H + N + B_{\text{torso}} + \text{Tail.Length}$$

This model ensures:

1. **$L$ is internally consistent:** The vertical stem equals the exact sum of its stick-and-oval components without coordinate clipping or scaling discrepancies.
2. **Structural differentiation is preserved:** A dowitcher has a high culmen-to-total ratio, an accipiter has a high tail-to-total ratio, and a heron has an elongated neck, matching field-guide proportions.

## 3. Web Application & Rendering Engine: `cmd/birdview`

### 3.1 Adaptive Geometric Binning (Row Breaks)

Linear bins (e.g., fixed 1-inch cuts) fail because bird morphology follows a power law: small birds cluster in the 4"–7" range, while larger raptors, owls, and waterfowl become isolated in solitary rows.

The binning algorithm groups species using an adaptive logarithmic anchor ratio:

1. Sort all visible, filtered birds ascending by the selected metric ($M_{\text{sort}} \in \{L, W, \text{Mass}\}$).
2. Set the first bird's metric as the row anchor: $A = M_{\text{sort}}[0]$.
3. Calculate the row ceiling: $C = A \times (1.0 + \alpha)$, where $\alpha$ is the configurable step ratio (default $\alpha = 0.15$ or $15\%$).
4. Group all subsequent birds where $M_{\text{sort}}[i] < C$ into the current row container.
5. When a bird meets or exceeds $C$, seal the row, establish that bird as the new anchor $A$, and repeat.
6. Display a tier header pill over every row showing the exact tier range:

$$\text{Tier } K: \quad \min(M_{\text{group}})\text{ to }\max(M_{\text{group}}) \quad (\text{Count species})$$

#### Coordinate Computation Logic (JavaScript / Web Component)

```javascript
function computeBirdCoordinates(bird, W = 160, H = 130, padY = 12) {
  const cx = W / 2;
  const availableH = H - (2 * padY);
  const scaleY = availableH / bird.totalMm;

  // 1. Bill (Stick)
  const culmenPx = Math.max(bird.culmenMm * scaleY, 4);
  const yBillTip = padY;
  const yCraniumTop = yBillTip + culmenPx;

  // 2. Cranium (Oval) - starts flush at cranium top
  const headHeightPx = Math.max(bird.headMm * scaleY, 10);
  const headRy = headHeightPx / 2;
  const headRx = Math.max(headRy * 0.9, 5.5);
  const headCy = yCraniumTop + headRy;
  const yNeckStart = yCraniumTop + headHeightPx;

  // 3. Neck & Shoulder (Crossbar attachment point)
  const neckPx = bird.neckMm * scaleY;
  const yShoulder = yNeckStart + neckPx;

  // 4. Torso Trunk
  const torsoPx = Math.max(bird.torsoMm * scaleY, 12);
  const yTorsoEnd = yShoulder + torsoPx;

  // 5. Tail Projection
  const tailPx = Math.max(bird.tailMm * scaleY, 8);
  const yTailTip = yTorsoEnd + tailPx;

  // 6. Horizontal Wingspan Crossbar
  const wingspanRatio = bird.wingspanMm / bird.totalMm;
  const maxSpanWidth = W - 24;
  const nominalSpanPx = (availableH * scaleY) * wingspanRatio;
  const wingSpanPx = Math.min(Math.max(nominalSpanPx * 0.65, 30), maxSpanWidth);

  return { cx, yBillTip, yCraniumTop, headCy, headRx, headRy, yNeckStart, yShoulder, yTorsoEnd, yTailTip, wingSpanPx };
}

```

### 4.4 `internal/morphology/anatomy.go`

```go
package morphology

import "math"

func Round1(val float64) float64 {
	return math.Round(val*10) / 10
}

// DeriveDimensions implements Option B: Computing macroscopic length and wingspan
// alongside segmented stick-and-oval coordinate budgets strictly from AVONET traits.
func DeriveDimensions(
	family string,
	culmenMm float64,
	depthMm float64,
	wingChordMm float64,
	secondaryMm float64,
	tailMm float64,
	massG float64,
) (totalMm, spanMm, headMm, neckMm, torsoMm float64) {
	meta, exists := SupportedFamilies[family]
	if !exists {
		meta = FamilyMetadata{Aspect: 1.0, Neck: 0.18}
	}

	// 1. Bill (Culmen)
	c := math.Max(culmenMm, 4.0)

	// 2. Cranium
	d := math.Max(depthMm, 3.0)
	headMm = math.Max(12.0, d*1.65)

	// 3. Torso Trunk Core derived from body mass allometry
	m := math.Max(massG, 5.0)
	torsoMm = 18.0 * math.Pow(m, 0.31)

	// 4. Neck Extension
	neckMm = torsoMm * meta.Neck

	// 5. Tail
	t := math.Max(tailMm, 6.0)

	// 6. Closed Total Length Budget
	totalMm = c + headMm + neckMm + torsoMm + t

	// 7. Wingspan Allometric Model
	chestBreadth := 10.5 * math.Pow(m, 0.33)
	secondaryRatio := 0.70
	if wingChordMm > 0 && secondaryMm > 0 {
		secondaryRatio = secondaryMm / wingChordMm
	}
	spanMm = 2.0*wingChordMm*(1.0+0.12*secondaryRatio)*meta.Aspect + chestBreadth

	return Round1(totalMm), Round1(spanMm), Round1(headMm), Round1(neckMm), Round1(torsoMm)
}
```

### 4.5 `cmd/birdview-ingest/main.go`

```go
package main

import (
	"encoding/json"
	"fmt"
	"log"
	"os"
	"strconv"
	"strings"

	"birdview/internal/morphology"
	"github.com/xuri/excelize/v2"
)

func main() {
	inputPath := "AVONET Supplementary dataset 1.xlsx"
	outputPath := "web/data/species.json"

	if len(os.Args) > 1 {
		inputPath = os.Args[1]
	}

	fmt.Printf("Reading %s...\n", inputPath)
	xl, err := excelize.OpenFile(inputPath)
	if err != nil {
		log.Fatalf("Failed to open workbook: %v", err)
	}
	defer xl.Close()

	// AVONET2_eBird uses Clements taxonomy
	sheetName := "AVONET2_eBird"
	rows, err := xl.GetRows(sheetName)
	if err != nil {
		log.Fatalf("Failed to read sheet %s: %v", sheetName, err)
	}
	if len(rows) < 2 {
		log.Fatalf("Sheet %s contains no rows", sheetName)
	}

	headers := make(map[string]int)
	for i, cell := range rows[0] {
		headers[strings.TrimSpace(cell)] = i
	}

	getCol := func(name string) int {
		if idx, ok := headers[name]; ok {
			return idx
		}
		return -1
	}

	sciIdx := getCol("Species2")
	famIdx := getCol("Family2")
	culmenIdx := getCol("Beak.Length_Culmen")
	depthIdx := getCol("Beak.Depth")
	chordIdx := getCol("Wing.Length")
	secIdx := getCol("Secondary1")
	tailIdx := getCol("Tail.Length")
	massIdx := getCol("Mass")

	if sciIdx == -1 || famIdx == -1 || culmenIdx == -1 || chordIdx == -1 || tailIdx == -1 {
		log.Fatalf("Missing required AVONET column headers in sheet %s", sheetName)
	}

	parseF := func(row []string, idx int, def float64) float64 {
		if idx == -1 || idx >= len(row) {
			return def
		}
		val, err := strconv.ParseFloat(strings.TrimSpace(row[idx]), 64)
		if err != nil || val <= 0 {
			return def
		}
		return val
	}

	var dataset []morphology.BirdSpecies
	seen := make(map[string]bool)

	for _, row := range rows[1:] {
		if len(row) <= sciIdx {
			continue
		}
		sci := strings.TrimSpace(row[sciIdx])
		if sci == "" || seen[sci] {
			continue
		}

		fam := ""
		if famIdx < len(row) {
			fam = strings.TrimSpace(row[famIdx])
		}

		meta, ok := morphology.SupportedFamilies[fam]
		if !ok {
			continue
		}

		culmen := parseF(row, culmenIdx, 0)
		depth := parseF(row, depthIdx, 6.0)
		chord := parseF(row, chordIdx, 0)
		sec := parseF(row, secIdx, chord*0.75)
		tail := parseF(row, tailIdx, 0)
		mass := parseF(row, massIdx, 25.0)

		if culmen <= 0 || chord <= 0 || tail <= 0 {
			continue
		}

		totMm, spanMm, headMm, neckMm, torsoMm := morphology.DeriveDimensions(
			fam, culmen, depth, chord, sec, tail, mass,
		)

		id := strings.ToLower(strings.ReplaceAll(sci, " ", "_"))

		dataset = append(dataset, morphology.BirdSpecies{
			ID:             id,
			CommonName:     sci, // Client substitutes colloquial common names or renders binomial
			ScientificName: sci,
			Family:         fam,
			FamilyCommon:   meta.Common,
			FamilyColor:    meta.Color,
			Regions:        []string{"US-NA"},
			LengthIn:       morphology.Round1(totMm / 25.4),
			WingspanIn:     morphology.Round1(spanMm / 25.4),
			MassG:          morphology.Round1(mass),
			TotalMm:        totMm,
			WingspanMm:     spanMm,
			CulmenMm:       morphology.Round1(culmen),
			HeadMm:         headMm,
			NeckMm:         neckMm,
			TorsoMm:        torsoMm,
			TailMm:         morphology.Round1(tail),
		})
		seen[sci] = true
	}

	if err := os.MkdirAll("web/data", 0755); err != nil {
		log.Fatalf("Failed to create output directory: %v", err)
	}

	outFile, err := os.Create(outputPath)
	if err != nil {
		log.Fatalf("Failed to create output file %s: %v", outputPath, err)
	}
	defer outFile.Close()

	enc := json.NewEncoder(outFile)
	enc.SetIndent("", "  ")
	if err := enc.Encode(dataset); err != nil {
		log.Fatalf("JSON encode failure: %v", err)
	}

	fmt.Printf("Successfully ingested %d species into %s\n", len(dataset), outputPath)
}
```

```go
package main

import (
	"embed"
	"fmt"
	"io/fs"
	"log"
	"net/http"
)

//go:embed all:web
var embeddedFiles embed.FS

func main() {
	port := "8080"

	// Strip the "web" prefix so files are served from root
	webFS, err := fs.Sub(embeddedFiles, "web")
	if err != nil {
		log.Fatalf("Failed to establish embedded web root: %v", err)
	}

	mux := http.NewServeMux()
	mux.Handle("/", http.FileServer(http.FS(webFS)))

	fmt.Printf("BirdView server running at http://localhost:%s\n", port)
	if err := http.ListenAndServe(":"+port, mux); err != nil {
		log.Fatalf("Server error: %v", err)
	}
}
```

```javascript
      const active = selectedFamilies.has(f.family);
      const btn = document.createElement("button");
      btn.className = `px-2.5 py-1 rounded-md text-xs font-medium transition-all flex items-center gap-1.5 border ${
        active ? "bg-slate-800 border-sky-500 text-white" : "bg-slate-950 border-slate-800 text-slate-400 hover:border-slate-700"
      }`;
      btn.innerHTML = `<span class="w-2 h-2 rounded-full" style="background-color: ${f.color}"></span> ${f.family} (${f.count})`;
      btn.onclick = () => {
        if (selectedFamilies.has(f.family)) selectedFamilies.delete(f.family);
        else selectedFamilies.add(f.family);
        renderChips();
        renderMatrix();
      };
      chipsContainer.appendChild(btn);
    });
  }

  // SVG Stick & Oval Abutment Rendering
  function buildSchematicSVG(bird) {
    const W = 160, H = 130, padY = 12, cx = W / 2;
    const availableH = H - (2 * padY);
    const scaleY = availableH / bird.totalMm;

    const culmenPx = Math.max(bird.culmenMm * scaleY, 4);
    const yBillTip = padY;
    const yCraniumTop = yBillTip + culmenPx;

    const headHeightPx = Math.max(bird.headMm * scaleY, 10);
    const headRy = headHeightPx / 2;
    const headRx = Math.max(headRy * 0.9, 5.5);
    const headCy = yCraniumTop + headRy;
    const yNeckStart = yCraniumTop + headHeightPx;

    const neckPx = bird.neckMm * scaleY;
    const yShoulder = yNeckStart + neckPx;

    const torsoPx = Math.max(bird.torsoMm * scaleY, 12);
    const yTorsoEnd = yShoulder + torsoPx;

    const tailPx = Math.max(bird.tailMm * scaleY, 8);
    const yTailTip = yTorsoEnd + tailPx;

    const wingspanRatio = bird.wingspanMm / bird.totalMm;
    const maxSpanWidth = W - 24;
    const nominalSpanPx = (availableH * scaleY) * wingspanRatio;
    const spanPx = Math.min(Math.max(nominalSpanPx * 0.65, 30), maxSpanWidth);

    return `
      <svg viewBox="0 0 ${W} ${H}" class="w-full h-full select-none">
        <line x1="${cx}" y1="${yBillTip}" x2="${cx}" y2="${yCraniumTop}" stroke="#f59e0b" stroke-width="2" stroke-linecap="round" />
        <ellipse cx="${cx}" cy="${headCy}" rx="${headRx}" ry="${headRy}" fill="#334155" stroke="#94a3b8" stroke-width="1.5" />
        <line x1="${cx}" y1="${yNeckStart}" x2="${cx}" y2="${yShoulder}" stroke="#94a3b8" stroke-width="2" />
        <line x1="${cx - spanPx / 2}" y1="${yShoulder}" x2="${cx + spanPx / 2}" y2="${yShoulder}" stroke="#0284c7" stroke-width="2.5" stroke-linecap="round" />
        <line x1="${cx}" y1="${yShoulder}" x2="${cx}" y2="${yTorsoEnd}" stroke="#64748b" stroke-width="4.5" stroke-linecap="round" />
        <line x1="${cx}" y1="${yTorsoEnd}" x2="${cx}" y2="${yTailTip}" stroke="#94a3b8" stroke-width="2" stroke-dasharray="3 1" stroke-linecap="round" />
      </svg>
    `;
  }

  // Geometric Binning & Row Render
  function renderMatrix() {
    container.innerHTML = "";

    const filtered = allBirds.filter(b => selectedFamilies.size === 0 || selectedFamilies.has(b.family));
    if (filtered.length === 0) {
      container.innerHTML = `<div class="p-8 text-slate-500">No species match the selected filters.</div>`;
      return;
    }

    const sorted = [...filtered].sort((a, b) => a[currentMetric] - b[currentMetric]);
    const groups = [];
    let currentGroup = [sorted[0]];
    let anchor = sorted[0][currentMetric];
    let ceiling = anchor * (1.0 + currentStepPct / 100);

    for (let i = 1; i < sorted.length; i++) {
      const val = sorted[i][currentMetric];
      if (val >= ceiling) {
        groups.push({
          min: currentGroup[0][currentMetric],
          max: currentGroup[currentGroup.length - 1][currentMetric],
          birds: currentGroup
        });
        currentGroup = [sorted[i]];
        anchor = val;
        ceiling = anchor * (1.0 + currentStepPct / 100);
      } else {
        currentGroup.push(sorted[i]);
      }
    }
    if (currentGroup.length > 0) {
      groups.push({
        min: currentGroup[0][currentMetric],
        max: currentGroup[currentGroup.length - 1][currentMetric],
        birds: currentGroup
      });
    }

    const unit = currentMetric === "massG" ? "g" : '"';

    groups.forEach((g, idx) => {
      const rowDiv = document.createElement("div");
      rowDiv.className = "bg-slate-900 border border-slate-800 rounded-lg p-4 mb-4";

      rowDiv.innerHTML = `
        <div class="mb-3 flex items-center justify-between">
          <span class="bg-slate-800 text-sky-400 text-xs font-semibold px-2.5 py-1 rounded border border-slate-700">
            Tier ${idx + 1}: ${g.min.toFixed(1)}${unit} – ${g.max.toFixed(1)}${unit}
          </span>
          <span class="text-xs text-slate-500 font-mono">${g.birds.length} species</span>
        </div>
        <div class="flex flex-row flex-wrap gap-3">
          ${g.birds.map(b => `
            <div class="w-44 bg-slate-800 border border-slate-700 hover:border-sky-500 rounded-lg p-3 flex flex-col justify-between transition shadow-sm">
              <div>
                <div class="font-bold text-xs text-slate-100 leading-tight mb-1 truncate" title="${b.commonName}">${b.commonName}</div>
                <span class="inline-block text-[10.5px] font-semibold text-black px-1.5 py-0.5 rounded leading-tight" style="background-color: ${b.familyColor}">
                  ${b.family}
                </span>
              </div>
              <div class="w-full h-32 my-1">
                ${buildSchematicSVG(b)}
              </div>
              <div class="pt-2 border-t border-slate-700 font-mono text-[10px] text-slate-400 flex justify-between">
                <span>L: ${b.lengthIn.toFixed(1)}"</span>
                <span>W: ${b.wingspanIn.toFixed(1)}"</span>
                <span>M: ${b.massG.toFixed(0)}g</span>
              </div>
            </div>
          `).join("")}
        </div>
      `;
      container.appendChild(rowDiv);
    });
  }

  // Controls Event Listeners
  metricButtons.forEach(btn => {
    btn.onclick = () => {
      metricButtons.forEach(b => b.classList.replace("bg-sky-600", "bg-slate-800"));
      btn.classList.replace("bg-slate-800", "bg-sky-600");
      currentMetric = btn.dataset.metric;
      renderMatrix();
    };
  });

  stepSlider.oninput = (e) => {
    currentStepPct = Number(e.target.value);
    stepValLabel.textContent = `${currentStepPct}%`;
    renderMatrix();
  };

  resetBtn.onclick = () => {
    selectedFamilies.clear();
    renderChips();
    renderMatrix();
  };

  renderChips();
  renderMatrix();
});

```

```bash
go run cmd/birdview/main.go
```
